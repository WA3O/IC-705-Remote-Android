# IC-705 Remote Control v28.37

Source release of the exact delivered v28.37 file.

Includes Connect/wake and optional standby on disconnect, LAN/WAN address selection,
startup audio/waterfall status, horizontal swipe tuning in 1 kHz steps, 10 kHz frequency
markers, thicker vertical lines, and the final 12.6-pixel frequency-label font.

The span-dependent 50/100 kHz marker spacing belongs to the later v28.38 follow-up
and is not included in this release. See [CHANGELOG.md](../../CHANGELOG.md) for the
full development history.

Replace the contents of MainActivity.kt in your Android project and rebuild. This
is a source release, not an APK. Use the file as a replacement, not as a second
class. Update Gradle versionName/versionCode separately if used.

For standby, select SET > Function > Power OFF Setting (for Remote Control) >
Standby/Shutdown and keep WLAN and Network Control enabled.

No additional compilation or live-radio testing was performed during publication.
